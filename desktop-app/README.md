# 马上下班

## 自动更新发布

应用已支持启动后自动检查新版本、右上角 `NEW` 提示、后台下载、SHA-256 校验和自动打开 DMG。

正式启用需要：

1. 将官网目录部署到 HTTPS 域名，并保证 `latest.json` 与 `downloads/` 可公开访问。
2. 把 `package.json` 的 `updateManifestUrl` 改为完整地址，例如 `https://example.com/latest.json`。
3. 每次发布更新 `latest.json` 的 `version`、`downloadUrl`、`sha256` 和 `notes` 后重新打包应用。
4. 对外分发建议使用 Apple Developer ID 签名并完成 notarization；否则用户下载新版后仍可能遇到 Gatekeeper 提示。

当前实现会自动下载并打开新版 DMG。要做到应用内完全静默替换旧版本，应在完成 Apple 签名、公证和稳定 HTTPS 更新源后接入差分更新服务。

一款懂打工人精神状态的桌面倒计时应用。输入下班时间后，可自由多选 3 小时、2 小时、1 小时、30 分钟、10 分钟和 5 分钟提醒，下班整点固定提醒。

## 直接安装 macOS 版

Apple Silicon（M1 / M2 / M3 / M4 / M5）Mac 可以直接打开 1.5.0 DMG，把应用拖入“应用程序”文件夹。

1.2.0 增加了动态精神状态图标；运行时，应用左上角头像与 macOS Dock / Windows 任务栏图标会随剩余时间变化。

1.2.1 修复了动态图标白色方框，并修复系统通知按钮误报成功的问题。按钮会先检查权限；权限关闭时可直接打开系统通知设置。

1.3.0 把首页大文案升级为 20 组“打工人情绪卡片”：每 30 秒自动轮播，窗口隐藏一会儿再打开会立即更新，也可以手动点击“换个精神状态”。一轮内尽量不重复。

1.4.0 把倒计时同步到应用图标：macOS Dock 使用动态时间徽标，最后 10 分钟逐秒倒数；Windows 任务栏使用适合小尺寸的小时/分钟紧凑角标，到点显示“下班 / GO”。

1.5.0 将进度条小人升级为原创矢量“工位生存小剧场”：敲电脑、喝茶、吃零食、喝奶茶、朝右跑步五套动作每 7 秒轮播；越接近下班，跑步出现得越频繁，最后 5 分钟持续冲刺。系统开启“减少动态效果”时会自动停用动画。

- 5 小时以上：额头贴“衰”的倒霉状态
- 5 小时以内至 1 小时以上：活人微死状态
- 1 小时以内至 5 分钟以上：开始期待状态
- 最后 5 分钟及下班后：迫不及待状态

此本地构建没有使用 Apple 开发者证书公证。如果系统首次阻止打开，请在 Finder 的“应用程序”中右键点击“马上下班”，选择“打开”，然后再次确认“打开”。

## 直接安装 Windows 版

Windows 10/11 64 位电脑运行 `马上下班-Setup-2.1.3-Windows-x64.exe`，跟随安装向导完成安装。安装器支持选择目录，并会创建桌面与开始菜单快捷方式。

此本地构建没有购买商业代码签名证书。如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息”→“仍要运行”。

## 运行桌面版

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

桌面版支持系统通知、提示音和窗口置顶。

## 直接预览

也可以直接双击 `index.html` 在浏览器中打开。浏览器版支持应用内提醒；授权通知权限后也能发送系统通知。

## 工位雷达：Cloudflare 真实数据

工位雷达保留两个完全隔离的数据源：

- `本地示例数据`：只使用 `app.js` 内置 mock，不请求定位、不连接网络。
- `云端真实数据`：用户主动开启附近发现后才请求定位；应用把位置发送给 Cloudflare Worker，服务端将坐标约化到 4 位小数（约 10 米网格）并存进私有 D1 数据库，只返回 1 / 5 / 50km 内、最近 30 分钟在线的匿名工友。经纬度不会返回客户端，50 米内和 100 米内仅返回近距离档位。

用户端不需要 GitHub 账号、令牌或 Cloudflare 凭证。D1 数据库绑定只存在于 Cloudflare 服务端，源码和安装包都不包含管理密钥。真实模式可向附近在线工友发送固定的匿名招呼，收件箱会显示服务端约化计算的当前距离，不下发对方经纬度。消息保留 30 天，每台设备每分钟最多发送 10 条。关闭附近发现会立即请求删除本机位置记录；即使网络中断，记录也会在 30 分钟后不再对其他用户显示，并在 7 天后清理。

### 无需打包的最简测试

1. 在本目录执行 `npm install`（依赖已安装时跳过）和 `npm start`。
2. 打开工位雷达，保持 `本地示例数据`，开启附近发现并切换范围；确认能看到原有 mock，系统不弹定位授权。
3. 切换到 `云端真实数据`，开启附近发现并允许定位；状态应显示已同步云端。应用无需填写任何凭证。
4. 在两台电脑（或两个隔离的 Electron `userData` 目录/两个系统账号）分别运行。两边都开启真实数据和定位，设置 50km 范围，刷新后应互相可见。不要复制 `radar-device.json`，否则会被当成同一设备。
5. 任意一边关闭附近发现，另一边刷新后不应再看到该设备。
6. 在一边点击“递杯水 / 摸鱼暗号 / 辛苦了”，另一边刷新后应在收件箱收到消息，并看到约化后的距离；“回个信号”应能真实回复。

日常开发和上述数据流测试都不需要重新打包。只有要把改动分发给其他电脑，或验证 macOS/Windows 安装包的定位权限、签名和启动环境时，才执行 `npm run build:mac` 或 `npm run build:win`。

## 功能

- 输入下班时间，自动识别今天或明天
- 3 小时、2 小时、1 小时、30 分钟、10 分钟、5 分钟六档自由多选提醒
- 下班整点固定提醒，不受多选设置影响
- 20 条随机主标题，每档 7 组随机打工人通知文案
- 首页 20 组完整情绪卡片每 30 秒自动轮播，支持回到窗口时更新和手动换一句
- 应用图标动态倒计时：macOS 最后 10 分钟逐秒跳动，Windows 使用紧凑小时/分钟角标
- 五套矢量动作轮播：敲电脑、喝茶、吃零食、喝奶茶、朝右跑步，临近下班提高跑步频率
- 应用内弹窗、Toast、提示音与系统通知
- 桌面窗口置顶
- 自动记住上次设置的时间
- 响应式布局、键盘焦点和减少动效支持
